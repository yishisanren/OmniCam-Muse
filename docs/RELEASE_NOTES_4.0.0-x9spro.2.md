## 修复与适配

- 大师色彩使用本机有效色温、动态 257 点 gamma 与四表 LMT，修复真实主图处理；HNCS 三颗后摄、Film Portra、Lumix 单色及混合强度完成代表性实拍。
- 进一步柔化接入本机 MTK GDF，0/50/100% 参数及成片验证通过；保留普通拍照作用域，GR、大师和高像素隔离通过，关闭后不残留上次强度。
- HDF 弱、黑柔中、白柔强完成主图 P010 处理和实拍；额外颗粒沿用原厂 Meishe V2，修复清透漏传颗粒类型，强度100下大小0/100通过。
- 和光物理胶片开关、XPAN 显影实况及小窗/大窗/动画净化完成实测。XPAN 最终 JPEG 保留85帧显影与AAC快门声，相册播放、另存视频通过。
- 4K60 反差黑白滤镜实录通过；专业视频主摄1→2×、长焦2.8→5.6×核对原厂传感器场景切换，4K30 SDR及10bit O-Log2实录通过。
- 修复 Mountify 遮挡原厂相机 SDK 登记的启动问题，保留 MTK 原始相机库、ISP、gamma、传感器条件和用户数据。

## 安装与回退

使用配对的 KSU ZIP（内置同版签名 APK），保留既有签名和应用数据。Aura 与 Muse 不应同时启用；LSPosed 作用域为系统框架、相机、相册。安装及重启后重新打开相机，核对 Muse 注入状态。不要清除相机/相册数据。

升级前保留当前 APK、模块和设置恢复点；回退只恢复本次涉及的模块和配置，不回灌旧媒体数据库覆盖照片。具体步骤见仓库 README 与 INSTALL_PLAN。

附件 APK、KSU ZIP 和 SHA256SUMS 为同一已验收版本。原始设备日志、照片和签名材料不随发行公开。
