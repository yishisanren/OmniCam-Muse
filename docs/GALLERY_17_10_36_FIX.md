# 相册 17.10.36 兼容修复

本地版本：4.0.0-x9spro.3 / 40003。目标为 Find X9s Pro、PME110_17.0.0.103(CN01)、相机7.006.121、相册17.10.36；未公开发布。

## 原因与修复

相册独立升级后，水印编辑段控件的 Kotlin 空值检查文案被删除。原符号规则依赖该文案，导致 `Section.segmentSetup` 及依赖它的 `Section.cameraStyles` 两个符号失败。改用 `watermark_camera_type_segment` 资源字段、无参数与void返回值联合定位；仍要求唯一匹配，保留调用关系校验。

GR 样式文件源类在新版 DEX 中不再提供原 String 构造器，反编译成 Java 后也不能据“没有显式构造器”推断其存在无参构造器。最终实现保留相册自己的样式源对象，在 `AssetManager.open` 的两个公开重载中只读取本机已分发的 `watermark_master_styles/gr_style_N.json`。其他资源走原厂路径，拒绝嵌套路径和目录穿越，缺失文件仍记录错误；不放宽诊断标准。

- 新相册实际打开归档测试照片的新副本，选择GR样式、应用并存为新图。JPEG为3208×5488，完整解码和前后传输哈希一致，目视确认机型文字及RICOH GR边框；输入副本未覆盖。
